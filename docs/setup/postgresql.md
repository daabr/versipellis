# Basic Setup of PostgreSQL for Versipellis

1. [Start a PostgreSQL Docker container](https://hub.docker.com/_/postgres)

   ```shell
   docker run --name my-postgres -p 5432:5432 -e POSTGRES_DB=versi_db \
          -e POSTGRES_USER=larry -e POSTGRES_PASSWORD=woof \
          --detach postgres:latest
   ```

   (Alternative: [download and install PostgreSQL](https://www.postgresql.org/docs/current/tutorial-start.html))

2. [Connect to PostgreSQL](https://www.postgresql.org/docs/current/app-psql.html)

   ```shell
   docker exec -it my-postgres psql --user=larry --dbname=versi_db
   ```

3. [Create a new table](https://www.postgresql.org/docs/current/sql-createtable.html)

   ```sql
   CREATE TABLE IF NOT EXISTS input_data (
       id        integer     PRIMARY KEY GENERATED BY DEFAULT AS IDENTITY,
       name      varchar(50) NOT NULL UNIQUE,
       last_seen timestamptz DEFAULT now() - random() * INTERVAL '1 year',
       rand_key  uuid        DEFAULT gen_random_uuid()
   );
   ```

   Optional check:

   ```sql
   \d input_data
   ```

4. [Insert rows into the table](https://www.postgresql.org/docs/current/sql-insert.html)

   ```sql
   INSERT INTO input_data (name) VALUES ('Alice'), ('Bob'), ('Carol'), ('Dave'), ('Eve');
   ```

   Optional check:

   ```sql
   SELECT * FROM input_data;
   ```

5. Exit

   ```
   \q
   ```
