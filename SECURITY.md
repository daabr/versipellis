# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1.0 | :x:                |

## Reporting a Vulnerability

Anyone can report vulnerabilities privately to the project's maintainers here:
<https://github.com/daabr/versipellis/security/advisories/new>

You may also contact the project owner directly (see contact details here: <https://github.com/daabr>).

### When Submitting a Report

To help us triage and remediate the issue efficiently, please include:

- Clear and detailed description and impact
- Affected version(s), setup, and configuration details
- Step-by-step reproduction instructions / minimal proof-of-concept (PoC)
- If possible: confirmed workarounds and patches, or remediation ideas
- All other details in the GitHub Security Advisories template

## Response Timeline

We will acknowledge receipt of any disclosure within 1 week, provide weekly progress updates of our investigation, and strive to release a fix within 30 days.

### Recognition

We will credit reporters of confirmed vulnerabilities publicly by mentioning their contributions in the relevant release notes and published security advisories, unless they request anonymity.
